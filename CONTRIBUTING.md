# Contributing to VIATAhos

Thank you for your interest in improving VIATAhos.
As a 64-bit operating system, entirely homegrown and driven by people, any help in writing the kernel, the T-CORE shell, and future modules is invaluable.

## Mandatory by.txt Submission for Credits
To maintain transparency regarding the authorship of the software and recognize everyone's work, we have a fundamental rule:
if you wish to contribute to the project, you must include your name or nickname in the file called **by.txt** located in the repository's root folder.

Pull Requests that modify the code but do not update the by.txt file with the respective developer's signature will not be accepted.
By completing this file, you ensure that your contribution remains in the VIATAhos history.

## License Acceptance
By submitting your code to any project within the VIATAhomebrew community, you agree that your changes will be released under the GNU GPL v3 license.
You'll retain ownership of your work by subscribing to by.txt, but you won't be able to request code closure in the future.
This ensures the system remains free for everyone, always.

## How to Start Contributing
1. Fork the repository you intend to work on.
2. Open the **by.txt** file and add your name to the bottom of the list.
3. Create a separate branch for your change, using a name that's clear for the feature you're developing.
4. Write clean, commented code designed specifically for 64-bit architectures, keeping in mind our alternative, anti-UNIX philosophy.
5. Verify that the code compiles correctly before proceeding.
6. Submit your improvements and change to by.txt via a Pull Request.

## Copyright and Attribution Notices
If your idea or code is inspired by another existing project, you must clearly state this in your proposal description.
Keep the original copyright notices intact within the source files, to respect the attribution chain required by the license.
