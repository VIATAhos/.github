# Security Policy

## Kernel Vulnerability Reporting
Since VIATAhos is a fully developed operating system based on an alternative architecture, low-level code stability is crucial. If you find a critical vulnerability, a serious error in 64-bit memory management, or a security flaw in the T-CORE shell, we ask you to follow these steps:

1. Do not file a public issue report. Publicly reporting a kernel issue before it's fixed could compromise other users' testing.
2. Contact the project managers privately by sending a message to the organization's key contacts or using the confidential reporting feature on GitHub.

We will investigate the issue as quickly as possible and fix it directly in our official repositories.
